# Orb Runner

A 3D platformer game developed with Unity.

## About the Game
Orb Runner is a level-based platformer where the player navigates through traps and obstacles to reach the final orb.

## Features
- 10 different levels
- Various traps and obstacles
- Physics-based movement
- Increasing difficulty progression

## Technologies
- Unity
- C#
